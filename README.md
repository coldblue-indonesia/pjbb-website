## 📋 Tentang

Website resmi **Perkumpulan Pejuang Batak Bersatu (PPBB)** — organisasi kemasyarakatan berbadan hukum yang memperjuangkan persatuan, pelestarian budaya Batak, dan kesejahteraan masyarakat berdasarkan Pancasila.

**Legalitas:** SK Kemenkumham RI No. AHU-0004388.AH.01.07.Tahun 2022

## ✨ Fitur Website

- 🎨 **Desain Modern** — Tailwind CSS dengan tema merah-emas khas Batak
- 📱 **Responsive** — Tampil sempurna di desktop, tablet, dan mobile
- ⚡ **Animasi Halus** — Counter animation, reveal on scroll, hover effects
- 🧭 **Navigasi Lengkap** — Header sticky, mobile menu, smooth scroll
- 📰 **Berita & Kegiatan** — Section informasi terkini organisasi
- 💳 **Donasi Online** — Integrasi QRIS, Transfer Bank, E-Wallet
- 📞 **Kontak & Form** — Formulir pesan dan info sekretariat

## 🛠️ Teknologi

| Teknologi | Keterangan |
|-----------|-----------|
| HTML5 | Struktur semantik |
| Tailwind CSS | Utility-first CSS framework |
| Font Awesome 6 | Ikon |
| Fontsource (Poppins & Open Sans) | Tipografi |
| Vanilla JavaScript | Interaktivitas tanpa framework |

## 🚀 Cara Menjalankan

### Cara 1: Langsung di Browser
Cukup buka file `index.html` di browser.

### Cara 2: Live Server (VS Code)
1. Install ekstensi **Live Server** di VS Code
2. Klik kanan `index.html` → **"Open with Live Server"**

### Cara 3: Python Simple Server

```bash
python -m http.server 8000
# Buka http://localhost:8000
